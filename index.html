Personal Project · May 2024 – Present · code ↗

AI Dungeon Master — a locally fine-tuned LLM agent

A Dungeons & Dragons game master built as a stateful LLM agent on a fine-tuned 7B model that runs on-device via its own OpenAI-compatible server — no cloud dependency at runtime.

  • LangGraph agent (rule-judge → narrator) with checkpointed memory — the LLM narrates while Python owns game state, dice and maps; Streamlit app with Whisper voice input and TTS.
  • Fine-tuned Qwen2.5-7B with QLoRA 4-bit (Unsloth + TRL) on curated D&D instruction data distilled from API transcripts — trained on a consumer RTX 5080, no cloud GPU spend.
  • Built an LLM-as-a-judge evaluation harness (weighted 1–5 rubric) over a held-out prompt set, running head-to-head comparisons of the cloud baseline vs. the fine-tuned local model.
  • Quantized to GGUF and benchmarked four levels (F16 → Q4_K_M: 14.2 → 4.4 GiB, ~2.4× faster); RAG (ChromaDB + MiniLM) injects top-k campaign-lore chunks into the narrator prompt.

MARS — Multi-Agent Pathfinding & Relocation Simulator

Real-time Pygame playground where many agents navigate to an exit/parking zone while avoiding obstacles and each other.

Personal Project · 2026

ESP32-S3 On-Device Gesture Recognition

Gesture classifier trained in Python, quantized to int8, and run on a microcontroller — optionally streaming to AWS IoT.

  • Collected and labeled MPU6050 IMU datasets over serial; trained a 1D CNN in Keras (≈95% float-accuracy target on 4 gesture classes; int8 stays within a few points).
  • Quantized float32 → int8 TensorFlow Lite Micro (model + scaler embedded as headers) for on-device inference.
  • Streamed detected gestures to AWS IoT Core over MQTT with mutual TLS for cloud analytics.
